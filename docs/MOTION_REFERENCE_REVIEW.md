## 实现决策

效果通过本项目已有的IntersectionObserver、Web Animations API和CSS实现。参考站的旧版整套框架未加入当前静态站点。没有滚轮接管、持续全页位移或新增自动轮播。

原有约540ms、16px的统一入场改为按内容选择：标题1050ms；图片与设备1200ms；其他内容960ms。使用柔和减速曲线，桌面上下移动42px、左右52px，同行间隔110ms且总延迟有上限。小屏缩为720ms、24px，横向改为纵向。

精确还原阶段已有部分HTML文字透明，由伪元素展示PSD字形。之前动画绑定这些透明文字，标题、联系信息、表单标题等实际图层未随之运动。本轮改为移动真正承载素材的容器，移除移动卡片内部的重复入场。图片增加轻微缩放和底部揭幕；结束即移除动画，回到原稿的布局、色彩和坐标。

首页标题、说明、按钮分别进入；主视觉1.8秒轻缓推近；手动切换为180ms退场加900ms入场。设备说明卡整体淡切，确保原稿素材和原生文字都参与运动，连续选择遵从最后一次操作。新闻图片1.1秒轻微放大，卡片650ms上移；应用图形、原生按钮和导航下划线提供柔和悬停反馈；设备就位后热点柔和显现，FAQ展开/收起使用380/260ms过渡。

保留键盘聚焦即显示、后台收敛、返回恢复、动态偏好切换和减少动态效果。动画默认一次播放；用户选择减少动态效果时直接展示最终画面。

## 验证

- 19项单元测试；7项内页浏览器回归、9项真实首页动效回归、4组静态表单及生命周期回归通过。
- 新增验证实际PSD标题容器参与入场、快速模块切换恢复原稿说明卡，以及轮播连续点击后文字/选择状态一致并可返回原稿首帧。
- 内页在1920/1280/761/760/390/360px检查横向宽度及关键交互。
- 本地第36轮八页按原始1920px、DPR1、默认内容及减少动态效果模式截图，全部差异像素为0。此项验证最终画面；动画过程通过允许动态效果的浏览器回归检查。
- 发布后继续用相同基准做公网截图及全部文件哈希校验。

- 允许正常动效后，第3轮动效终态截图逐区滚动触发、等待自然结束，再返回页首；八页整页及各分区同样为零差异。
- 复现正常动效终态：`node scripts/capture-pages.mjs http://127.0.0.1:5173/ .design/precision-review/motion --settle-motion`，随后运行对应目录的 `compare-psd.py`。此模式不强制完成或跳过任何已注册动画。
