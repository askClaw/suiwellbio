# 动效连续性修复方案

本轮逐帧复查覆盖首页和七个内页。实施前按影响范围、原稿版式、快速连续操作和减少动态效果四项复核。

| 区域 | 修复方案 | 验收条件 |
| --- | --- | --- |
| 首屏 | 固定照片与控件坐标。三张使用同一套原生标题和说明，按各自最长内容预留空间。保留错峰淡入，切换时缩短淡出和淡入。轮播指示条在固定点击区域内变色、伸缩。 | 首次入场和切换期间，按钮和箭头坐标保持稳定。360/390 px 下第三张两行说明可完整阅读。三张字号、字重、基线一致，快速点选以最后一次为准。 |
| 热点与计数 | 说明卡统一使用原生结构，按最长说明定高，仅淡切文字。热点、文字和连线在同一次提交中切换，连线从当前路径继续。两项百分比从计数到完成使用同一套 SVG 字形。 | 卡片尺寸保持一致。计数末帧和终态的数字像素一致。连线最终仍锚定选中热点。 |
| 悬浮电话及悬停 | 电话用单个听筒和胶囊，展开后淡入完整号码，收起前淡出。胶囊右边缘固定，号码直接使用拨号入口的数据。桌面页脚保留原稿文字，悬停用下划线反馈。 | 鼠标、键盘和小屏上都能复现对应状态。听筒只绘制一次，号码与拨号链接一致。页脚文字位置固定。 |
| 服务、菜单与搜索 | 下载入口接入共用弹窗。弹窗不缩放文字，遮罩同步淡入淡出。FAQ 用统一的卡片框和图标状态，答案、反馈面板和意见框使用高度过渡。移动菜单重开时从当前帧继续。搜索在页头下方浮层出入。 | 关闭按钮、遮罩和 Esc 可退出弹窗并恢复焦点。FAQ 可快速反向切换并保留草稿。搜索开合时正文坐标固定。 |
| 新闻 | 分类和分页采用全状态共用的原生排版。分页维持相同尺寸与对齐。 | 1920 px 切换到第 2 页及切回后，分页按钮位置、尺寸、字号保持一致。分类切换和浏览器前进后退正确恢复。 |

方案复核确认，首屏字形、百分比、说明卡、FAQ 框和新闻控件会有局部桌面像素变化。以统一交互状态及保留照片、其他原稿素材和页面分区尺寸为验收依据。用现有动画控制器处理取消与后台收尾，保留原生详情、表单和键盘路径。

## 实施与复验

- 构建、语法检查、19 项单元测试和 28 项浏览器回归通过。电话工具栏单独在 11 组页面与视口组合验证，含鼠标悬停、展开中间帧、键盘聚焦、滚动固定和返回顶部。
- 320、360、390、761、1280 和 1920 px 下，逐张核对首屏标题、说明、按钮、箭头和轮播指示的尺寸与坐标。两项百分比在手机、平板和桌面以实际像素尺寸渲染。桌面最后计数帧和终态裁图逐像素一致。
- 在 390 和 1920 px 实点下载入口，分别用关闭按钮、遮罩和 Esc 关闭并验证焦点返回。FAQ 草稿、新闻前进后退和减少动态效果通过回归。
- 1920 px 下对比八页修改前后的截图，页面总高度、分区起点和高度一致。图片、背景和字体均加载成功。原稿导出规则在临时目录重新生成并核对，避免覆盖本轮连续性修复。
- 浏览器验收使用 Chrome 桌面与模拟移动视口。
