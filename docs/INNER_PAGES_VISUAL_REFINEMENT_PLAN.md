# 内页 UI 与动效调整方案（已自审）

状态：已实施并完成浏览器回归，结果见 `INNER_PAGES_VISUAL_REFINEMENT_RESULT.md`。范围为本轮静态内页及其共用动效，保留首页既有行为。

## 1. 目标与边界

- 以本地 v02 PSD 为布局、图形、颜色基准；参考代码及网站用于交互节奏，不照搬与原稿冲突的视觉。
- 优先处理区块比例、参数信息层级、缺失背景，再处理动效。
- 新闻继续使用现有真实静态记录；FAQ 继续按问题和答案版本保留页面内反馈；联系表单继续为静态演示。
- 不增加视频、后台接口、自动轮播、虚构新闻、证书或下载文件。本轮不包含提交 commit 或发布。
- 修改生成器、模板、样式和数据源后统一构建，避免只修改根目录生成的 HTML。

## 2. 基准与测量方法

桌面主基准：1920px 宽、浏览器缩放 100%、字体与图片加载完成、入场效果结束。每页记录 banner、标题、卡片、区块边界的位置，并与 PSD 同尺寸叠图。

产品页已测基准（单位 px，存在像素取整）：

| 对象 | PSD | 当前 | 调整方向 |
| --- | ---: | ---: | --- |
| 核心单元区高度 | 约718 | 807 | 减少约89，核对标题留白及两行卡片 |
| 产品优势区高度 | 约910 | 986 | 减少约76，核对卡头、正文及最小高度 |
| 工作流程区高度 | 约444 | 473 | 减少约29，校准标题至节点及底部留白 |
| 技术参数区高度 | 约863 | 992 | 恢复内部结构后重新测量，不直接定高 |
| 应用入口区高度 | 约230 | 201 | 补足原稿比例，不统一压缩所有区块 |
| 底部方案区起点 | 约3621 | 3919 | 消除前序累积偏差 |
| 横幅设备图左侧 | 约1037 | 1150 | 左移约113，保持约408×223比例 |

验收建议：桌面主要内容左右锚点误差不超过8px，标题/卡片/区块纵向锚点误差不超过12px，产品页方案区累计偏差不超过24px。字体缺失或内容差异导致无法达到时，逐项记录原因，不裁切正文或写死高度来通过。

公司页、工艺能力、服务、新闻列表、详情、联系页先补齐同类测量表。工艺稿顶部100px多余画布留白继续排除；不同新闻正文、占位内容及反馈功能导致的高度差异单独注明。

## 3. 调整任务与顺序

### A. 布局与排版校准（P2）

涉及：`pages.css`、`scripts/build-pages.mjs`，必要时新增内页专用 class。

1. 核对实际字体、字重和换行；有可用正式字体才接入，否则保留一致的回退字体并记录差异。禁止横向拉伸文字或用大量手工换行模拟字体。
2. 产品页逐区校准标题顶距、标题与内容间距、卡片行高/内边距、网格间距及底部留白。调整顺序从上到下，每区测量后再继续。
3. 设备图使用产品横幅专用布局，将文字区与图形区按PSD锚点定位；中等宽度切换自适应，手机继续上下排列，不使用跨断点的固定左移。
4. 参数内容恢复后再确定参数区高度；应用入口区单独恢复高度比例。
5. 其余六页核对列宽、图片裁切、标题层级和留白，重点检查公司工厂图、服务时间线、联系卡片、新闻正文。
6. 共用 `.section-title`、`.soft-section` 等规则只在证据支持时调整；优先限定到页面/区块，防止修产品页时改变首页和其他内页。

验收：达到第2节锚点目标；正文完整；卡片不依赖固定总高度；桌面与手机无溢出、遮挡和异常断词。

### B. 技术参数结构恢复（P2）

涉及：`site-data.js`、`scripts/build-pages.mjs`、`pages.css`。

1. 将单一参数与复合参数区分建模。复合参数使用带 label/value/unit 的子项数组；技术指标按 PSD 原文核对，不在视觉调整时推断或改写。
2. 流量精度、压力、pH、电导四卡恢复并排的浅底子单元，明确“量程/精度”等对应关系。
3. 单一参数保留大数值与独立单位；长尺寸数值在手机上按分隔符合理换行，不任意拆分数字或单位。
4. 保留外层定义列表语义，子项标签与数值在无CSS时仍能顺序阅读。

验收：16组参数齐全；复合参数的标签和值逐项对应；1920px四列、手机两列均能完整阅读；构建后内容无丢失。

### C. 公司页背景恢复（P2）

涉及：`scripts/extract_inner_assets.py`、`assets/inner/`、`pages.css`。

1. 确认山景的图层、蒙版、混合模式与原稿裁切，分别导出核心优势背景和使命卡片背景。
2. 使用装饰背景或伪元素承载，保持正文为真实文本；还原浅色雾化、青色叠色和山峰位置。
3. 避免仅导出未合成的原始图层导致效果偏差；导出后与原稿局部对照，选合适的WebP尺寸和质量。
4. 手机重新裁切，保持正文对比度；图片未加载时有底色兜底。

验收：两个区域都有正确山景层次；不改变布局高度；不引入原先排除的带非商用标记素材。

### D. 流程图呈现与动效（P2）

涉及：生成器、`pages.css`、`common.js`，仅在需要时增加 `pages.js` 的专用编排。

1. 桌面保留六节点横排、虚线连接及PSD第二节点的默认强调状态。
2. 将连线与节点视作一个视觉组件，禁止节点位移时连线独立常驻。建议整组淡入，节点仅做短距离错峰淡入；如采用位移，则连线同步显现，避免连接错位。
3. 首选一次滚动入场；悬停/键盘聚焦只强化当前节点。结束后不持续自动切换节点，不默认添加无限流动虚线。
4. 手机改为单列纵向流程，沿节点中心设置竖向虚线，编号保持1至6的阅读顺序；线条自适应内容高度。
5. 参考时长：整体450–550ms，节点间隔60–80ms，同一组最大额外等待不超过240ms。最终以实际滚动观感校准。

验收：入场、悬停、聚焦、缩放时连线与圆心保持连接；页面后台恢复和减少动态效果模式无残留隐藏；手机流程方向清楚。

### E. FAQ 反馈渐进展开（P2）

涉及：生成器、`pages.css`、`pages.js`，保留现有 feedback store。

1. 答案下默认只显示“是否有帮助”的紧凑选项和简短静态说明。
2. 选择“没有帮助”后展开可选意见框；选择“有帮助”仍提供“补充意见”入口，两种选择都可以记录。
3. 保留明确的记录按钮及“仅本页记录，未发送”提示，不增加虚假提交状态。
4. 隐藏意见框时保留已输入内容；切换问答、切换评价和重新展开均不清空。隐藏控件不参与键盘焦点。
5. 反馈区域变化与外层FAQ开合统一管理，防止外层高度动画截断新内容；快速切换时从当前视觉高度接续，完成后恢复自然高度。
6. 展开不抢焦点；用户主动关闭包含焦点的区域时，焦点返回对应展开控件。反馈提示避免每次展开重复播报。

验收：默认反馈区域目标高度约70–100px，不要求整个服务页与原稿等高；无反馈表单的原始区块单独对照PSD。长意见、连续切换、手机键盘和减少动态效果均无截断或数据丢失。

### F. 内页分组入场（P3）

涉及：生成器、`common.js`，沿用既有动画控制器。

1. 为卡片网格配置明确组容器，再注册入场；专用注册先于通用 `[data-entry]`，避免被现有去重逻辑跳过。
2. 按同一批进入视口的同行卡片顺序错峰，不按整页索引累积延迟；建议70ms间隔、最大140ms。
3. 时间线桌面左右交错轻移，手机统一短距离上移；避免父容器与子元素叠加入场。
4. 保留首屏立即可见规则；不为了展示动效重新隐藏已经显示的内容。所有入场只执行一次。
5. 保留后台恢复、焦点进入即显示、减少动态效果和旧动画回调隔离机制；不扩大本轮到重写共用动画系统。

验收：同行错峰可辨认但不拖慢阅读；快速滚动不闪烁、不长时间留白；回滚页面不反复播放；首页设备、热点及连线行为不变。

## 4. 验证与交付

1. 先完成A/B/C的静态视觉，截图确认后再实施D/E/F；FAQ高度按新功能单独复核。
2. 桌面1920px与PSD叠图；1280px及761/760px断点检查；手机390px与360px检查。覆盖全部七个内页，首页做共用样式回归。
3. 截图需等待字体、图片及入场完成；同时检查常规动态效果、减少动态效果。静态截图不代替动画检查。
4. 动态手工验收：慢滚/快滚、往返滚动、悬停与键盘聚焦、动画中改变视口、切后台再回来、FAQ快速连续开关与反馈展开。
5. 执行 `npm run build`、`npm run check`、`npm test`；运行既有首页原生浏览器动效回归页。
6. 仅为新增的实际风险补充测试：复合参数构建后的标签和值完整性；FAQ折叠意见仍保留内容；外层开合与意见展开交错时无高度残留。行为测试验证实际DOM与最终状态，不只复述实现。
7. 交付关键区块前后对照图、锚点偏差表、测试结果和仍需正式素材/字体的差异清单。更新静态实施文档。

## 5. 方案 Review 与修正结论

| 检查点 | 初始风险 | 本方案修正 |
| --- | --- | --- |
| 追平服务页总高度 | 新增反馈和占位文字本来就比PSD多，强压高度会截断内容 | 拆开原稿区块还原与新增功能验收，不以整页高度判错 |
| 直接固定区块高度 | 字体/窄屏/长文本变化后溢出 | 用间距、列宽和内容结构校准，保留自然高度 |
| 新增动效分组无效 | 通用注册先执行，专用注册会被去重 | 先专用后兜底，并验收真实延迟 |
| 时间线统一改变方向 | 连线固定、父子双重移动造成错位 | 只对卡片轻移，节点/线保持连接，避免嵌套动画 |
| 给流程图加自动循环 | 超出当前交互需求，分散阅读注意力 | 一次入场、悬停/聚焦反馈，不自动轮播 |
| 缩小FAQ却损失反馈 | 好评无法补充、切换后意见被清空 | 两类评价都可展开意见，隐藏不清值 |
| FAQ嵌套高度动画 | 外层动画使用旧高度，内层展开被裁切 | 同步更新/结束外层高度效果，终态回到自然高度 |
| 修改共享样式 | 首页或其他内页被意外改变 | 页面/区块级覆盖优先，包含首页回归 |
| 背景导出失真 | 裸图层忽略蒙版/叠色 | 按可见合成效果导出并局部核对 |

结论：按上述修正后可进入实施。执行顺序为基准测量 → 布局/参数/背景 → FAQ与流程组件 → 分组动效 → 全站视觉和交互回归。没有需要先接入后端或补视频才能推进的依赖；正式字体与缺失业务资料作为明确差异记录。
