## 3. 动效规范

以下为首轮实施参数，视觉验收时允许小幅调整；不以精确毫秒替代实际观感。

| 场景 | 时长 / 位移 | 触发与约束 |
| --- | --- | --- |
| 标题、描述入场 | 480–560ms / 上移 12–18px | 首次进入视口；局部错峰 60–80ms。 |
| 设备、公司介绍主体入场 | 560–640ms / 16–24px；设备缩放 0.985→1 | 每个目标一次；保留设备水平居中定位。 |
| 新闻、应用、页脚组 | 480–560ms / 12–18px | 同组错峰 60–80ms；最大额外等待 160ms。 |
| 普通悬停 | 180–240ms / 上浮 2–5px | 零等待；键盘焦点提供等效强调。 |
| 设备热点切换 | 220–280ms | 高亮立即反馈；卡片和连接线同步过渡；最后一次操作优先。 |
| 菜单 / 弹窗打开 | 220–280ms / 6–12px | 状态可中断，禁止重复绑定处理器。 |
| 菜单 / 弹窗关闭 | 140–180ms / 4–8px | 完成退出后才隐藏或执行原生关闭。 |
| 首屏手动切换 | 280–360ms / 8–12px | 只切换标题和描述；按钮及轮播控制保持稳定。 |

入场使用平滑减速；关闭更短。禁止给组件设置无差别 `transition: all`，禁止让入场错峰延迟影响悬停和焦点反馈。

## 4. 具体修复

### A. 入场失效与页面层次

问题：`.unit-card`、`.about-features > span`、`.footer-grid a` 的 transition 覆盖了入场属性；整个标题块一起出现，层次偏平。

实施方式：

1. 入场统一由专用控制器执行，使用 Web Animations API 管理有限时长动画；CSS 只管理组件的悬停、焦点和视觉外观。移除旧 `[data-motion]` 对 opacity / translate / scale 的 transition，避免两个系统同时插值。
2. 入场控制器持有每个目标的状态：`pending → running → complete`，并记录动画句柄。取消时显式落到最终可见状态，不残留隐藏类或内联中间值；完成后释放动画效果和句柄，避免 forwards 填充长期压住组件样式。
3. 同一同步任务内撤销 pending 隐藏并启动动画；静态 HTML 默认可读，初始化失败或不支持动画时直接显示内容。只有初始化成功的目标才进入 pending。
4. 保持 `.machine-stage > .machine` 的定位关系，设备入场使用独立的 translate / scale 属性，不覆盖 `transform: translateX(-50%)`，不在设备和定位父容器之间插入 wrapper。
5. 热点卡片外壳负责入场，内部内容容器负责切换；避免两种动画操作同一元素的透明度和位移。
6. 标题按英文眉题、中文主标题、装饰线、说明分层；装饰线随主标题出现，说明滞后约 80ms；主体可见时独立入场，不等待整个大型 section 都进入视口。
7. 公司介绍只让外壳做轻微入场；内部特征项优先做短透明度过渡，避免父子两层同时大幅移动。页脚保持浅色 PSD 设计，各列依次出现。
8. 错峰在各局部组内计算；手机单列时按当前可见目标触发，不让下方卡片继承桌面第三列的等待时间。
9. 键盘聚焦 pending 内容时立即使其可见；深链接、历史恢复和初始已可见的内容优先可读，避免整块空白后补出现。

验收：产品卡、公司特征、页脚品牌均有实际过渡；动画期间设备居中、热点和连线不漂移；快速滚动后无永久空白；停止 JavaScript 或开启减少动态效果时内容完整可读。

### B. 数字倒跳与不自然的中间值

问题：初始终值可先被看到，触发时又回到零；`±0.1%` 只有两档变化；`7×24h` 经过 `7×0h` 等非业务展示状态。

实施方式：

| 指标 | 最终策略 |
| --- | --- |
| `50%+`、`30%` | 仅这两项使用约 1000–1200ms 的缓动递增。 |
| `7×24h`、`<60s`、`±0.1%`、`GMP/FDA` | 完整终值保持不变，使用轻微遮罩揭示或透明度入场；不生成其他业务数值。 |

- 静态 HTML 保留真实终值，供无脚本与辅助技术读取；动画用独立的视觉节点，辅助技术只读取完整终值，不播报逐帧更新。
- 初始化时，只有确定位于视口下方的待计数项才预置视觉零值，并在接近进入视口时开始计数。初始已可见、深链接或历史恢复时已可见的数字直接保留终值，不重置。
- 数据区可见性触发时，按同一可见行协调两项数字的起点；不要求手机上下两行同时开始。
- 使用等宽数字和按终值预留的稳定宽度，避免递增推动百分号、相邻列或文字居中位置。
- 只执行一次。减少动态效果、页面进入后台或动画中断时落到准确终值，不在返回页面时重新从零开始。

验收：慢速滚动录像中没有“终值→零”的倒跳；不存在 `7×0h`、`±0.0%`；不会因小数舍入出现两档伪递增；刷新、深链接、前进后退与返回前台时终值正确。

### C. 新闻卡片延迟与反馈一致性

问题：入场延迟 0 / 100 / 200ms 同时作用在悬停和离开上。

实施方式：

- 错峰延迟仅存于入场控制器的动画参数，不写入组件全局 `transition-delay`。
- 新闻卡的位移、阴影、边框固定零延迟，图片略慢于卡片；离开时立即开始恢复。
- 入场与悬停可以同时发生，各自使用不同属性：入场用 opacity / translate，悬停用 transform。二者不重置彼此的状态。
- 保留现有图片、标题、阅读全文的实际点击范围；悬停强调以这些入口为主，避免空白区域看起来是一个失效按钮。
- 为键盘 `focus-within` 提供相同强调；纯触控不保留悬停抬起状态，按压只提供短反馈。

验收：三张卡片的悬停、离开和聚焦响应均为零额外等待；快速横移没有第三张“跟不上”的现象；入场未结束时悬停也不会跳回原位。

### D. 热点、说明卡和连接线同步

问题：连接线端点直接跳变；快速选择会创建多段未管理的卡片动画；不同文字高度可能改变连线起点。

实施方式：

1. 记录“最新请求的热点”、当前已渲染状态和当前动画句柄。相同热点不重复播放；新请求取消旧动画，以当前画面为起点继续，旧完成回调不得覆盖新选择。
2. 选中点和 `aria-pressed` 立即更新；说明卡内容只更新到最后一次请求。视觉切换限定在内部内容区，外壳保持稳定。
3. 按当前卡片宽度预留四份内容需要的最大自然高度。测量节点不可聚焦、对辅助技术隐藏、无重复 ID；字体加载或宽度变化时重新测量，不固定一个容易截字的像素高度。
4. 连接线统一表示为四个折线节点，桌面路径允许重复节点，手机使用同一节点数量。使用同一时间轴插值节点数值，同时更新轨道和虚线；不依赖浏览器自动插值 SVG `d`。
5. 路由先避开说明卡边界：端点位于卡片右侧时从右边出线，否则从底边出线，转折保留约 16–24px 的空间；不能让线路穿过说明文字。切换过程中从当前节点继续过渡，不从上一个目标重新开始。屏幕跨断点、缩放或重新布局时取消位置动画并立即重算，优先保证端点准确。
6. 布局读取集中在选择、图片/字体就绪与 resize 时；逐帧只插值缓存数值并写路径，不逐帧调用尺寸测量。ResizeObserver 的重算合并到单次 requestAnimationFrame，避免读写循环。
7. 虚线流动仅在产品交互区域可见且页面处于前台时播放；减少动态效果时静止。悬停、键盘、触控共用同一选择函数，不自动轮换热点。

验收：连续快速切换至少 10 次后，选中点、文字和线终点始终一致；动画中途改变宽度后端点准确；没有越来越多的并行动画、卡片高度跳变或 ResizeObserver 循环警告。

### E. 弹窗、菜单的退出动画与焦点

采用可中断状态：`closed → opening → open → closing → closed`。每次状态变化带操作标记，异步完成前检查是否仍为当前操作。

弹窗：

- 所有关闭入口统一走 `requestCloseDialog()`：关闭按钮、遮罩、Esc。
- 原生 `cancel` 事件先阻止默认立即关闭；退出完成后再调用 `dialog.close()`。退出期间仍保持模态、背景不可操作与页面滚动锁定。
- 动画正常结束、被取消或切换到减少动态效果时，都执行同一份幂等清理；不能仅依赖 transitionend，也不能遗留滚动锁。
- 关闭过程中重新打开时撤销旧关闭任务；已打开时切换内容不重复调用 showModal。
- 保存实际打开入口；关闭完成后恢复到仍存在、可见且可用的入口，否则使用合理的页内后备位置。
- 锁滚动时保持滚动条占位，避免整页横移。关闭不改变原滚动位置。

手机菜单：

- 开关按钮、Esc、外部点击和导航链接走同一状态逻辑；关闭动画结束前保留渲染，结束后才隐藏并移出键盘顺序。
- Esc 关闭后焦点回到菜单按钮；点击导航链接后保留锚点导航的焦点/滚动意图；点击外部控件时不强行抢回焦点。
- 关闭期间重开可中断。切到桌面断点时清理手机状态，显示完整桌面导航，不残留 hidden / inert / aria-expanded 错误状态。
- 锚点跳转沿用当前吸顶导航偏移，并重新核对滚动高亮；不在同一点击上叠加两段互相竞争的滚动动画。

验收：关闭按钮、Esc、遮罩都具有短退出过渡；连续开关、快速重开和退出中切断点后页面可操作；焦点不会丢到页面顶端或隐藏菜单；不会锁死滚动。

### F. 首屏与正式视频

可立即完成的工作：

- 分离标题/描述的切换层与固定 CTA；点击轮播时按钮、左右箭头和指示器不跟随整块内容淡出。
- 预留当前宽度下最长文案所需空间，三份文案切换不推动 CTA、轮播指示器或首屏高度。
- 同一切换控制器处理快速连续点击；最后一次点击结果优先，旧动画不覆盖新文案。保留手动切换。
- 无视频时继续显示 PSD 原图，不重复制造“背景已切换”的假象。入场只播放一次，手动切换使用较短过渡。

正式视频到位后完成的工作：

- 使用真实视频与 poster；配置 muted / playsinline，提供明确的暂停/继续入口。静音自动播放失败时保留 poster，并允许用户手动播放。
- 减少动态效果时默认展示 poster，由用户主动播放；首屏离开视口或页面进入后台时暂停，用户主动暂停后不自动恢复。
- 明确用户暂停、离屏暂停、后台暂停三种原因，避免滚动回来强制覆盖用户选择。
- 视频加载失败保持 poster、文案和 CTA 可用，不展示浏览器错误图标。
- 本地预览同步支持正确的视频 MIME 与 Range 请求；大文件流式发送，防止一次性读入整个视频。

依赖说明：正式视频的实际画质、剪辑、体积和自动播放表现必须在素材提供后验收。其他修复可以独立交付，不把缺失素材记作“视频已完成”。

### G. 减少动态效果与后台行为

- 统一媒体偏好入口，只管理本页面动效模块创建的动画，替换当前对 `document.getAnimations()` 的全局处理。
- 偏好在动画中改变时：入场与计数显示最终状态；热点落到最新选择；关闭中的菜单/弹窗完成清理；停止装饰虚线。不得遗漏异步关闭回调。
- 页面隐藏时停止装饰动画，有限时长的入场/数字落到终态；恢复前台不重复入场。视频遵循自身暂停原因。
- 禁用动画时仍保留必要的选中、焦点和展开状态，交互结果不依赖动画完成事件才能生效。

## 7. 对本方案的 review 及修订结果

### 发现并已修订的问题

| 方案风险 | 原因 | 最终处理 |
| --- | --- | --- |
| 到处添加入场 wrapper 会破坏设备定位。 | 热点坐标依赖 `.machine-stage` 和设备的 offset，居中使用 transform。 | 设备 DOM 定位关系不变，独立属性做入场；只给热点卡片内容增加切换容器。 |
| CSS 修复后继续共享 transition-delay，悬停仍可能延迟。 | CSS 简写会覆盖之前的属性，错峰属于入场生命周期。 | 入场由独立控制器持有延迟；组件 CSS 的悬停延迟恒为零。 |
| 所有指标换成数字滚轮，仍会出现无意义数据。 | 显示机制改变不等于业务语义正确。 | 只对 50/30 递增，其他四项显示真实完整终值。 |
| 给已可见数字初始化零值仍会产生倒跳。 | 页面可能初始较高、恢复历史位置或直达锚点。 | 初始化已可见数据直接终值，只有屏下目标准备计数。接受“部分初始可见场景不计数”的取舍。 |
| 直接给 SVG d 加 CSS transition，表现依赖路径和浏览器。 | 桌面/手机折线节点不同。 | 四节点数值插值；resize 时取消旧位置动画并直接重算。 |
| 最近的热点可能位于卡片右边界内侧，直接向右出线会穿过卡片。 | 单一路由方向无法适应所有设备点位。 | 根据点位选择右边或底边出线，路径避开卡片文字。 |
| 快速热点切换导致旧动画/旧回调干扰。 | 当前实现未管理动画句柄。 | 模块持有唯一切换操作，取消旧操作，从当前渲染状态过渡。 |
| 只延迟 dialog.close，Esc 仍会立即关闭。 | 原生 cancel 默认行为绕过退出流程。 | 统一处理 cancel、按钮、遮罩；退出完成后再原生关闭。 |
| 关闭时统一恢复按钮焦点会抢走导航/外部点击焦点。 | 不同关闭原因有不同用户意图。 | 按原因恢复；链接与外点不强制回到菜单按钮。 |
| 减少动态效果时只关 CSS 会遗留关闭和滚动锁。 | JS 状态仍在等动画完成。 | 媒体偏好变化同时完成各模块状态与清理；不依赖事件一定发生。 |
| 等待视频导致全部修复无法交付。 | 正式素材缺失是独立依赖。 | 阶段 1–7 独立验收；视频明确列为阶段 8。 |

方案覆盖五项 review 问题及两项设计改善，修改范围、状态所有权、依赖和验收路径已明确；目前未发现阻止阶段 1–7 实施的方案缺口。
