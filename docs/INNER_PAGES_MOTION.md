# 内页动效补齐

七个内页沿用首页的可取消入场控制器，补充首屏标题、说明文字和产品图入场；首屏内可见的内容也播放动效。滚动到内容区后，卡片与标题保持既有错峰，工作流程改为逐步骤入场，服务阶段和说明分别呈现，避免父子层重复位移。

新增 FAQ 标题、应用领域、联系信息、咨询字段和新闻正文的入场；新闻分类切换后，可见的新卡片重新播放入场。补充参数与下载卡片悬停、图标反馈、FAQ 加号旋转及输入框聚焦过渡。

保留后台收尾、减少动态效果、键盘聚焦立即显示和新闻节点清理机制。未添加自动循环装饰动画，数值与技术参数保留原值。

验证：

- `npm run build`、`npm run check`、`npm test` 通过，18 项自动化测试通过。
- Chrome 无头浏览器实际加载生产页面：内页 7 项、首页动效 7 项、静态表单与注册清理 4 组回归全部通过，无脚本异常。
- 七个内页覆盖 1920、1280、761、760、390、360px 宽度，无横向溢出。
- 验证首屏动画实际运行与完成、卡片 0/70/140ms 错峰、流程逐项入场、键盘聚焦、FAQ 快速切换和减少动态效果。
- 测试为 Chrome 模拟视口；未进行 Safari 或真实手机验收。
