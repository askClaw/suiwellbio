## 页面和结构

- `about.html`：公司简介、原稿工厂图、两地地图、核心优势、使命与价值观。
- `product.html`：独立产品横幅、核心单元、优势、6步流程、16组参数、应用入口。
- `process.html`：四段体系、技术团队与原稿照片、三个证书占位。
- `service.html`：服务体系、左右交错时间线、FAQ手风琴、逐条静态反馈、四份下载占位。
- `news.html`：两种分类、真实数据分页、状态参数与卡片。
- `news-detail.html`：按 ID 读取文章，完整正文/摘要区分、返回列表和同分类下一篇；未知 ID 显示未找到。
- `contact.html`：统一联系信息、静态咨询表单、前端校验与明确的未发送提示。

共用页头、页脚、咨询横条和导航在构建时生成真实 HTML，不依赖客户端注入才能看到内容。导航使用真实页面路径，当前页按路由高亮。

原首页脚本拆分为 `common.js` 和 `home.js`，由 `app.js` 按页面初始化；内页不再访问不存在的首页设备或轮播元素。`pages.js` 管理内页交互，`site-data.js` 和 `page-model.js` 分离内容与数据逻辑。

## 边界

手机为浏览器模拟视口，尚未做真实手机/Safari实机验收。图片与字体仍应按最终素材核对；正文中的技术指标按设计稿录入，不代表外部核验。该轮没有发布到外部站点，也没有新增 Git commit。

后续内容编辑请修改模板/数据再运行 `npm run build`；静态页保存在仓库根目录，可由普通静态 HTTP 服务直接提供。
