# PSD 视觉校准记录

基准为 `resource/v02/` 的 1920px 设计稿，浏览器使用 1920px 视口。图片中的文字与标题保留相应的 HTML 文本供辅助技术读取；页面内容、链接、表单和交互仍由 HTML 生成。运行 `scripts/extract_psd_artwork.py` 可从本地 PSD 重新生成本轮新增的素材。

## 本轮调整

- 首页：按原稿调整产品展示、应用、公司、新闻和咨询横条的区块边界；首屏标题及主要分区标题使用 PSD 像素图层；产品和公司背景、工厂图从独立图层合成，消除旧截图素材中的重影。
- 共用区域：内页横幅、咨询横条改用 PSD 背景，导航使用原稿图标及下拉标记；桌面内页标题使用原稿文字图层。
- 产品：核心单元背景、四个核心图标和六个优势图标采用原稿图层。
- 工艺与服务：四阶段服务图标使用原稿图层；工艺页团队图标着色及证书两侧装饰调整，证书框保持原稿空白外观。
- 公司：两地布局图标及四张原稿优势卡使用 PSD 图层。
- 联系：使用原稿工厂渐隐合成、六个联系图标，并校准桌面联系卡的左右分栏。
- 新闻和新闻详情：应用共用导航、标题、横幅及咨询横条的校准；现有真实静态数据、分类、分页和文章链接逻辑保持不变。

## 尚未达到逐像素一致的部分

- 正文字体文件未随 PSD 提供。部分原稿标题已直接使用其文字图层，但正文和动态文案仍使用系统字体，字形、字距和换行有差异。
- 新闻列表原稿以三条样例重复形成六张卡片，当前页面按实际静态数据筛选，因此卡片数和页面高度不同。服务 FAQ 反馈、静态下载状态及联系表单提示属于现有功能，额外占用高度；联系页主体也沿用现有统一联系方式，与 PSD 主体另一套信息不同。
- 首页应用区、产品应用条和服务流程中的六边形图案所在 PSD 图层名称标明“仅供交流学习非商用”；当前没有使用该图层，背景仍有差异。
- 证书、真实下载文件、二维码和视频仍无正式资源。原稿多个静态占位和当前真实功能状态的展示不同。
- 各页仍有卡片内文字换行、图标颜色、局部间距等差异；本轮没有完成所有区域的逐像素差异消除，也没有在 Safari 和真实手机设备上验收。

## 验证

`npm run build:site`、`npm run check` 和 `npm test` 通过。浏览器中三组回归分别为内页 7 项、首页动效 7 项、静态表单及生命周期 4 组；内页检查覆盖 1920、1280、761、760、390 和 360px。浏览器回归验证布局和交互，不等同于完整的视觉像素验收。
