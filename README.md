# 穗维卓生物首页

根据 `resource/v02/demo.psd` 实现的静态首页，使用 HTML、CSS 和原生 JavaScript，无前端依赖。

## 本地预览

```sh
npm run dev
```

访问 http://localhost:5173 。页面使用原生 ES Modules，请通过 HTTP 预览。

- `index.html`：页面结构与原稿文案。
- `styles.css`：桌面与手机布局。
- `app.js`：轮播、产品热点、弹窗、搜索和移动导航。
- `assets/`：从 PSD 提取的设备、品牌和新闻图片。
- `scripts/extract_assets.py`：素材提取脚本，需要 Python 的 `psd-tools` 和 `Pillow`。

导航链接定位首页相关区域；其他 PSD 对应的独立内页不在此次实现范围。设计稿未提供视频、英文内容、新闻完整正文和正式二维码，因此相应入口有明确说明，二维码保留原稿占位。电话及邮件可直接调用设备应用。上线前需要补充真实备案号和上述内容。轮播仅有一张原稿图片，三页沿用该图并切换文案。

运行 `npm run check` 检查 JavaScript 语法。

## 动效细节

保留 PSD 版式，视频以外的动效修复已实施。`motion.css` 控制悬停外观，`app.js` 与 `motion-core.js` 分别管理入场、切换和退出，避免属性与延迟互相覆盖。

- 标题、说明、设备、新闻和页脚按局部组首次入场；初始已可见内容优先保持可读。
- 仅 50%+、30% 递增；其余四项显示真实终值。初始化已可见的数字不重置；宽度按终值随响应式字体预留。
- 热点支持悬停、键盘和点击，四节点连接线同步过渡；快速重选以最后一次为准，说明卡按当前宽度预留最大内容高度。
- 新闻悬停、聚焦即时反馈，入场错峰不影响交互。
- 菜单、弹窗有打开及退出动画，统一处理 Esc、取消、焦点与滚动锁。导航在 960px 以下折叠，页面主体在 760px 以下切换手机布局。
- 首屏手动切换只影响文字，CTA 保持可见且位置稳定。没有自动轮播或热点自动循环。
- 系统减少动态效果或页面进入后台时，有限动画完成到终态，装饰虚线停止。只清理本页面创建的动画。
- 视频未接入，仍使用 PSD 设备图。

```sh
npm run check
npm test
```

8 项核心回归检查覆盖旧回调、减少动态效果、快速重选、resize 中断和连接线路由。浏览器与设备验证结果见 `docs/MOTION_REPAIR_VERIFICATION.md`，实施方案见 `docs/MOTION_REPAIR_PLAN.md`。

### Review 后的三项回归修复

- 错峰入场使用 `fill: backwards`，等待期间维持初始隐藏态，完成后释放动画效果。
- 页面转入后台仅完成正在播放的任务，待入场内容和计数器保留；返回前台主动恢复当前可见目标。减少动态效果仍直接显示全部终态。
- 设备图片入场期间，热点和连线暂时隐藏；设备落定后恢复，避免在动画期间使用最终坐标造成错位。

启动预览后打开 `http://localhost:5173/tests/motion-browser.html`，点击“运行回归检查”。5 项浏览器回归在 iframe 中加载真实首页，仅测试页模拟可见性变化，生产页面不包含测试开关。
